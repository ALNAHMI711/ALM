# YOW Content & Commerce Portal

البوابة التي سيستخدمها اللاعب:
- إنشاء حساب/تسجيل الدخول.
- شراء اللعبة أو Content Packs.
- رؤية حالة الدفع.
- إعادة تنزيل APK والمحتوى المدفوع لاحقًا.
- إدارة الجهاز/الجلسات.
- عرض الإعلانات والمواقع المتاحة للحجز.

## نموذج الاستحقاق
Payment Provider -> Webhook -> Order -> Entitlement -> Signed Download Token.

لا نعتمد على عنوان IP أو IMEI وحده لإثبات الشراء. الحساب + جهاز مسجل + entitlement خادمي أفضل، مع سياسة نقل/إلغاء جهاز واضحة.

## الإعلانات
نوعان:
1. Billboard: لوحة إعلانية محدودة العدد.
2. Sponsored Location: اسم راعٍ لموقع داخل الخريطة.

لكل نوع مخزون مستقل، سعر مستقل، مدة، حالة، صورة إثبات، ومراجعة إدارية.

## الإطلاق
زر Launch في لوحة التحكم يغيّر حالة الحملة/الإصدار، لكنه لا يحذف الحجوزات. بعد الإطلاق يمكن استمرار بيع المساحات المتبقية أو إيقافها نهائيًا حسب إعدادات المشرف.

## التنزيل المدفوع والتخزين

مسار التنزيل الحالي مصمم على مبدأ: الاستحقاق أولًا، ثم رابط تخزين قصير العمر.

1. يسجل اللاعب الدخول ويملك entitlement فعالًا للمنتج المطلوب.
2. يربط Installation/Device ID مولدًا من التطبيق بالحساب؛ لا نعتمد على IMEI أو IP لإثبات الملكية.
3. يوجد ربط مستقل بين الجهاز وكل Product/Content Pack يملكه الحساب؛ لذلك لا يكفي أن يكون الجهاز صحيحًا للحساب إذا لم يكن المنتج نفسه مربوطًا به.
4. يصدر الخادم Download Token قصير العمر مرتبطًا بالحساب والمنتج والجهاز.
5. يتحقق مسار التنزيل من الجلسة والاستحقاق والجهاز وربط الجهاز بالمنتج والـ token قبل إصدار الرابط.
6. لا يعيد المسار رابط التخزين الدائم؛ بل يطلب من StorageSigner إصدار URL مؤقت.
7. HmacStorageSigner المضمن هو عقد تكامل Gateway/CDN تحت سيطرتنا، وليس ادعاءً بأن أي S3/CDN عشوائي يفهم توقيع HMAC هذا.
8. مدة رابط التخزين محدودة حاليًا بحد أقصى ساعة، والبوابة تستخدم 5 دقائق للتنزيل.
9. مفاتيح التخزين تُعامل كـ object keys وتُرفض مسارات traversal أو المسارات المطلقة.

متغيرات البيئة ذات الصلة:
- YOW_CORE_ARTIFACT_KEY: مفتاح الكائن المدفوع داخل التخزين، وليس رابطًا عامًا.
- YOW_STORAGE_GATEWAY_URL: عنوان HTTPS للبوابة/الخدمة التي تتحقق من توقيع التخزين.
- STORAGE_SIGNING_SECRET: سر توقيع روابط التخزين، ولا يجب وضعه في المستودع.

مهم للإنتاج: قبل بيع APK فعليًا، يجب ربط StorageSigner بمزود تخزين/CDN حقيقي يطبق التوقيع والتحقق من انتهاء الصلاحية على جهة التخزين. لا نضع APK المدفوع كـ public GitHub Release asset.
