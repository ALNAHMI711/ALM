# YOW Content & Commerce Portal

البوابة التي سيستخدمها اللاعب:
- إنشاء حساب/تسجيل الدخول.
- شراء اللعبة أو Content Packs.
- رؤية حالة الدفع.
- إعادة تنزيل APK والمحتوى المدفوع لاحقًا.
- إدارة الجهاز/الجلسات.
- عرض الإعلانات والمواقع المتاحة للحجز.

## نموذج الاستحقاق
Payment Provider -> Webhook -> Order -> Entitlement -> Signed Download Token.

لا نعتمد على عنوان IP أو IMEI وحده لإثبات الشراء. الحساب + جهاز مسجل + entitlement خادمي أفضل، مع سياسة نقل/إلغاء جهاز واضحة.

## الإعلانات
نوعان:
1. Billboard: لوحة إعلانية محدودة العدد.
2. Sponsored Location: اسم راعٍ لموقع داخل الخريطة.

لكل نوع مخزون مستقل، سعر مستقل، مدة، حالة، صورة إثبات، ومراجعة إدارية.

## الإطلاق
زر Launch في لوحة التحكم يغيّر حالة الحملة/الإصدار، لكنه لا يحذف الحجوزات. بعد الإطلاق يمكن استمرار بيع المساحات المتبقية أو إيقافها نهائيًا حسب إعدادات المشرف.
