# اليمن — مشروع لعبة عالم مفتوح

اسم العمل: **Yemen Open World (YOW)**

> لعبة أصلية ثلاثية الأبعاد للعالم المفتوح، مستوحاة من ألعاب العالم المفتوح دون نسخ أصول أو كود أو خرائط محمية من ألعاب أخرى.

## الحالة
- المستودع الحالي كان يحتوي ملفات بيانات/مودات قديمة مرتبطة ببنية GTA.
- تم فصلها منطقيًا عن النواة الجديدة.
- النواة الجديدة تستهدف Unity 2022.3 LTS أو أحدث إصدار LTS متوافق.
- Android هو الهدف الأول.
- Offline-first: بعد تنزيل المحتوى المرخص تعمل الخريطة والمحتوى الأساسي دون اتصال.

## التصميم
1. APK صغير نسبيًا للنواة.
2. Content Packs منفصلة: World / Vehicles / Weapons / Audio / Cosmetics.
3. Manifest موقّع يحدد المحتوى المتاح وإصداره.
4. بوابة ويب للتحقق من الشراء وإتاحة التنزيل.
5. إعلانات ومواقع تجارية ديناميكية عبر Content Manifest، بدون إعادة بناء APK لكل إعلان.
6. لوحة تحكم: نشر/إيقاف الحملة، الأسعار، المخزون، الدول/المناطق، المحتوى، وطرق الدفع.

## الملكية والحقوق
لا تستخدم أصول GTA أو خرائط Google/Apple أو شعارات الشركات أو نماذج سيارات/أسلحة غير مرخصة داخل النسخة التجارية. ملفات المستودع القديمة محفوظة كمرجع تقني فقط ويجب مراجعة ترخيصها قبل أي استخدام.

## الدفع
التصميم يدعم مزود دفع قابل للاستبدال. لا نخزن بيانات البطاقات داخل اللعبة. بعد نجاح الدفع يصدر الخادم entitlement موقّعًا مرتبطًا بحساب المستخدم والجهاز، مع سياسة إعادة تنزيل واضحة.

## أول خريطة
اليمن هي الخريطة الأولى المقترحة: صنعاء، عدن، تعز، الحديدة، إب، حضرموت وغيرها، مع بيئات أصلية مستوحاة من الواقع. لا نستخدم بيانات جغرافية محمية دون ترخيص.

## الأمان
- لا أسرار داخل Git.
- لا مفاتيح دفع داخل APK.
- تحقق خادمي من الاستحقاق.
- التوقيع الرقمي للـ manifests.
- تنزيلات HTTPS.
- SHA-256 للتحقق من الملفات.
